# Benchmark Analysis - November 21, 2026 (task 501)

Every framework except PowerArgs parses the same argv: `--str "hello world" -i 13 -b`. PowerArgs
still parses `/str:hello world /int:13 /bool`. Nuru maps the route
`--str {str} -i {i:int} -b` with `NuruApp.CreateBuilder()`, its only builder. The Cold job is the
first call in a fresh process (JIT included). The Warm job is the steady-state cost of one call.

- BenchmarkDotNet v0.16.0-preview.2, .NET 11.0.0, X64 RyuJIT x86-64-v4
- AMD Ryzen 9 7950X3D, Ubuntu 26.04 LTS (other builds were running on the machine)
- Run: `cd benchmarks/timewarp-nuru-benchmarks && dotnet run -c Release -- --filter '*'`

## The December 2025 "full builder" regression

The 2025-12-20 run put "TimeWarp.Nuru (Mediator)" last at 131.96 ms and 221 KB. That case was
`NuruApp.CreateBuilder(args)` with `services.AddMediator()` (the martinothamar Mediator package)
and a runtime Microsoft DI container and configuration (`commands/nuru-mediator-command.cs` at
8cebb25a). Task 330 (January 2026) removed the Mediator packages and that benchmark, and removed
`CreateSlimBuilder` and `CreateEmptyBuilder`. Since then the generator emits only what an app
uses: `Build()` creates a `NuruApp`, services are built on first read, and `Map<T>()` endpoints
dispatch through the source-generated TimeWarp.Mediator. The path that regressed no longer exists;
`CreateBuilder` is now the 9.3 ms row above. The `operation-dispatch` dev benchmark measures the
generated mediator path per call.

## What changed in task 501

Measured with `dev benchmark run <name> --base <ref>` (interleaved base and head samples):

| Benchmark | Base | Head | Verdict |
| --------- | ---: | ---: | ------- |
| startup-first-call (fresh JIT process) | 20.1 ms | 14.9 ms | win (0.74) |
| startup-warm-call | 6.0 µs | 3.1 µs | win (0.53) |
| operation-dispatch (mediator per call) | 5.07 µs | 2.75 µs | win (0.54) |
| aot-startup | 2.83 ms | 2.83 ms | noise |

- The CLI signal wrapper no longer subscribes to `Console.CancelKeyPress` for the console terminal;
  that first subscription initialized the console (about 5 ms cold). Posix SIGINT and SIGQUIT
  registrations, made once per process, deliver Ctrl+C and Ctrl+Break.
- No blank configuration root is built when nothing reads it.
- The `--json-args` reader and selection and the `InvokeAsync` switch are separate generated
  methods, so a plain argv run does not JIT-compile them. `ExecuteRouteAsync` still names
  `JsonDocument`, so System.Text.Json can still load on that run.

AOT startup stays at the process-start floor. The cross-framework AOT table
(`runfiles/aot-benchmark.cs`) was not refreshed: that runfile no longer compiles against the
current TimeWarp.Amuru API.
